# Teaching Notes

- 教材主线是证据依赖，不是项目评分或选型排行榜。
- Outcome、Process、Safety、Reliability、Cost 不能压成一个总分。
- 每个项目章至少有练习、验收和检查理解。
- 第 1–6 章复用 Support Ticket Agent；τ-bench 再扩展动态用户。
- Langfuse 与 Phoenix 是并列 evidence 案例，不互为产品先修。
- Inspect 与 τ-bench 放在后段，因为它们要求先理解 metric、trace 和环境证据。
- 第 8 章综合实践是主线收束点；四份 appendix 属于研究与参考。
