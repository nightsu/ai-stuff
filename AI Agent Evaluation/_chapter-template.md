# Agent Evaluation 教学章节模板

> 用于后续扩展课程，不属于主线。

## 写作原则

1. 先说明本章补齐评价栈的哪一层；
2. 功能列表必须落到 Task、Trial、Evidence、Grader 或 Decision；
3. 版本、许可与部署放入维护附录，正文只保留会改变 API 或测量结论的边界；
4. 至少包含一个测量失真反例；
5. 优先复用 `CASE-STUDY.md`，避免每章更换业务领域；
6. 必做练习控制在 30–90 分钟，并把进阶/生产化内容分层；
7. 练习必须产生可重复的 task、trial、score 和 failure analysis；
8. 章末在 `SOLUTIONS.md` 提供判分点和常见错误；
9. 平台特有结构允许覆盖通用模板。

**章节标题：第 N 章 项目/方法——本章评价问题**
