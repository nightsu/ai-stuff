# Mission: AI Agent Evaluation

## Why

把分散的评价框架、benchmark 和论文整理成一套可实践的教材，最终能够独立定义“什么叫 Agent 做对了”，并建立可重复、可解释、可持续的评价系统。

## Success looks like

- 能设计 Task Contract、Harness、Evidence 和 Grader；
- 能区分 Agent failure 与评价基础设施 failure；
- 能校准 LLM judge 并表达非确定性；
- 能把 CI 与生产反馈连接起来。

## Constraints

- 先讲测量问题，再讲平台功能；
- 确定性证据优先，模型评分补位；
- 研究排名和项目状态不决定课程顺序；
- 内容增加以提升实验与归因效率为准。

## Out of scope

- 给出一个万能 Agent 总分；
- 用公开 leaderboard 代替产品评价；
- 把框架能力矩阵当作评价有效性的证明。
