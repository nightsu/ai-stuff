# Separate deterministic Evidence Gating from model review

Publication first passes a deterministic Evidence Gate for scope, hashes, ranges, lineage, classification, references, authorization, and budget compliance, then receives an advisory Evaluator Review based only on each Claim and its cited evidence. The model review cannot override a hard gate or approve publication; its versioned verdicts and uncertainties are shown to the user and bound into the final publication approval, avoiding the false assumption that an LLM judge is a deterministic oracle.
