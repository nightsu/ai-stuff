# Use a deterministic workflow around the Research Loop

The Evidence Research Agent uses a deterministic outer workflow for plan approval, scope enforcement, validation, publication approval, and terminal-state handling, while the model controls only a bounded Research Loop for searching, reading, and closing evidence gaps. This preserves explicit governance and testable phase boundaries while still exposing the open-ended decision-making that the project exists to teach; a fully autonomous loop was rejected because it would make mandatory controls optional model choices.
